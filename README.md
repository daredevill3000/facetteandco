# Facette&Co — Complete Website Prototype

This is a single deployable static website containing the homepage, commercial routes, supporting pages, enquiry flows, responsive design, motion, reduced-motion support, SEO-ready semantic HTML, sitemap and robots file.

## Brand direction
The visual system is derived from the supplied Facette&Co logo: deep emerald green, white/porcelain, black, mint material tones and fine geometry. The prior dark charcoal / champagne-brass direction has been intentionally replaced for this build.

## Hero
The homepage hero uses a custom inline SVG faceted diamond ring structure with autonomous rotation, cursor perspective influence and four restrained sparkle particles. Rotation is intentionally faster than the earlier prototype.

## Important asset note
Conceptual material visuals are CSS-generated placeholders. Replace them with approved company photography before launch. They are not presented as client work.

## Forms
All forms are frontend-only because no database/backend was supplied. Connect the form submit handlers to the chosen secure endpoint/CRM before production.

## Pages
The site contains the brand, gemstone, collaboration, Metalworks, luxury object, proof/trust and knowledge routes, plus project enquiry/RFQ flows.


## Visual asset note
This build uses editorial stock photography served from Unsplash as visual references. These are not Facette&Co-owned photos and must not be represented as commissioned Facette projects. Replace them with approved company photos when supplied. The logo supplied by the client is included locally.
